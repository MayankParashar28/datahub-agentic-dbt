# monthly_revenue

## Purpose
Monthly aggregated revenue cohort model built strictly from DataHub ledger metadata.

## Grain
One row per month and payment method channel.

## Sources
- `finance.transactions` (Snowflake)

## Lineage
- **Upstream**: `payments.events` (Kafka) -> `finance.transactions` (Snowflake)
- **Downstream**: `analytics.monthly_revenue`

## Transformations
- `date_trunc('month', transaction_timestamp)` -> `revenue_month`
- `sum(gross_amount - coalesce(discount_amount, 0))` -> `net_revenue`

## Data Quality Tests
- `revenue_month`: `not_null`
- `net_revenue`: `not_null`

## Metadata Gaps
> [!WARNING]
> **Currency definition unavailable**: DataHub column metadata for `gross_amount` does not specify currency ISO code.

## Assumptions
- **No currency conversion applied**: Preserved native ledger values.
- **Time Zone**: Assuming `transaction_timestamp` is in UTC.
